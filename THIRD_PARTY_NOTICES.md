# Third-Party Notices

Creator OS-owned source code is MIT unless a file states otherwise.

Third-party dependencies remain under their respective licenses. Before adding a dependency, contributors must verify its license, maintenance status, distribution implications, security posture, and model-weight license when applicable.

This file will be expanded as runtime dependencies are integrated.

## Current and planned external components

The following projects are used through package managers/adapters or are being evaluated; inclusion here is not a claim that their source code has been copied into Creator OS:

- Tauri — Apache-2.0 / MIT
- React — MIT
- Axum — MIT
- Tokio — MIT
- Tower / Tower HTTP — MIT
- Rust ecosystem crates — individual package licenses
- FastAPI — MIT
- FFmpeg / FFprobe — licensing depends on build configuration; Creator OS does not currently bundle a binary and must not silently distribute a GPL build without an explicit licensing decision

AI code licenses and model-weight licenses must be reviewed separately.
