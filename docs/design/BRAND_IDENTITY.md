# Creator OS visual identity: Totem Cut

Totem Cut (concept 3, premium/minimalist logo exploration) is the selected identity. Its geometric three-layer emblem represents creation, editorial transformation, and an integrated creator operating system.

Canonical vector masters: `assets/brand/`. UI mark: `apps/desktop/public/branding/totem-cut-app-icon.svg`. Tauri app icons: `apps/desktop/src-tauri/icons/`.

Brand is governed by `assets/brand/README.md`. The approved reference is an AI-rendered visual direction and not a mathematically exact source; the production mark is an SVG reconstruction.

The design constitution still applies: shared tokens, light/dark contrast, minimal chrome, accessibility, and screenshot review before merge.

Review and release gates: 16px/24px legibility, dark/light UI visibility, native Windows/macOS/Linux icon packaging, and trademark similarity review. Do not reintroduce a generic text-letter placeholder.
